# ASHBOUND · 용의 맹약

[게임 플레이](https://tazan12.github.io/ashbound-dragon-oath/)

PC·모바일 브라우저용 싱글플레이 드래곤 액션 RPG, 버전 0.26.0.
사냥과 장비 성장, 드래곤과의 맹약, 성채 전투와 영토 공방을 진행합니다.

## 시작

게임 링크 → **게임 시작** → 캐릭터 선택 → **이야기 시작하기**.
모바일은 가로 화면과 가벼운 화질을 권장합니다. 첫 실행 시 약 82 MB를 받습니다.
게임 안의 임무/메뉴에서 현재 줄거리와 조작 설명을 확인하세요.
진행도는 현재 브라우저에 저장되며 기기·주소 간 자동 동기화되지 않습니다.

## 배포

이 저장소는 컴파일된 WebGL 실행 파일과 시작 화면을 보관합니다.
Unity 개발 소스와 제작 설정은 별도의 비공개 저장소에 보관합니다.
`main` 브랜치의 루트가 GitHub Pages에 자동 배포됩니다.
`.nojekyll`을 유지하고 `assets.json`과 `Build` 파일을 같은 버전으로 함께 갱신하세요.

서체 라이선스는 `fonts/OFL.txt` 및 `fonts/NotoSerifKR-OFL.txt`에 포함되어 있습니다.
이 저장소의 공개는 게임 코드·이미지·모델에 대한 별도 재배포 라이선스를 부여하지 않습니다.
